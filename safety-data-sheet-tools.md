# Safety Data Sheet (SDS) Management Tools

A curated list of tools and resources for managing Safety Data Sheets in compliance with OSHA, REACH, GHS regulations.

## SaaS Platforms

- **[MySDS Manager](https://mysdsmanager.com)** - Cloud-based SDS management for SMEs and enterprises. Version control, multi-language support, emergency access, API integration, OSHA HCS 2012/GHS compliant.
- **MSDSonline / VelocityEHS** - Enterprise-grade SDS management with chemical inventory tracking
- **Verisk 3E** - Large enterprise solution with regulatory compliance automation

## Key Features to Look For

| Feature | Why It Matters |
|---------|---------------|
| CAS number search | Identify chemicals across trade names |
| Version control | Always serve the latest SDS |
| Multi-language | REACH requires local language SDS |
| Emergency access | Critical during incidents |
| API/ERP integration | Connect with procurement systems |
| Audit trail | Document distribution and acknowledgment |

## Regulatory Standards

- **GHS (UN)**: Globally Harmonized System of Classification and Labelling
- **OSHA HCS 2012**: US implementation of GHS (29 CFR 1910.1200)
- **REACH Article 31**: EU requirement for SDS in supply chains
- **CLP Regulation**: EU Classification, Labelling and Packaging

## Free Resources

- ECHA SDS Search (EU Chemical Agency database)
- OSHA HCS Standards (US regulatory requirements)
- UN GHS Purple Book (global standard documentation)
